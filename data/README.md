# Example plates

## Synthetic full-assay plate

`synthetic-reader.csv`, `synthetic-map.json` and `synthetic-truth.json` are generated by `lab_assay.demo.synthetic_plate(seed=2026)`. They are synthetic endpoint absorbance-like signals, not physical measurements. Standards use `0.07 + 2.7/(1+(x/7)^1.3)` with small seeded Gaussian noise. DEMO-S1 and DEMO-S2 have original concentrations of 7 and 12 ng/mL and dilution factors of 2 and 3. There are 39 occupied wells; the other wells are unmapped. The control signals are independently generated, not re-labelled standards.

Regenerate the example files with:

```sh
uv run python -m lab_assay.demo --db demo.sqlite --export demo-output
```

## Public calibration wells

`public/elisatools-standards.csv` contains **measured** standard wells from the first plate in [ELISAtools Assay_2.txt](https://github.com/cran/ELISAtools/blob/d28128c9c29c52a9e52c7896e500010536cdcd0b/inst/extdata/Assay_2.txt). Feng Feng published the example under the MIT license. The [annotation](https://github.com/cran/ELISAtools/blob/d28128c9c29c52a9e52c7896e500010536cdcd0b/inst/extdata/AnExp_2plate.txt) identifies A1:H3 as triplicate standards s1 through s8; [stdConc.txt](https://github.com/cran/ELISAtools/blob/d28128c9c29c52a9e52c7896e500010536cdcd0b/inst/extdata/stdConc.txt) gives their concentrations.

I keep only these 24 calibration wells. I subtract the second wavelength (620 nm) from the first (450 nm). Source concentration units are unspecified, so I call them source units and do not assign ng/mL. All sample wells and labels are excluded. No public-patient values are included.

The subset has extra provenance columns and is consumed by `tests/test_public_data.py`, not directly by the two-column reader importer. It is a calibration regression example, not a full-QC plate: it lacks independent controls, separate blanks and verified unknown concentrations. The synthetic plate provides those deliberately controlled test conditions.

`public/provenance.json` records the pinned source commit, transformation and SHA-256 hashes. `public/LICENSE-ELISAtools.txt` retains the upstream license. Reproduce the subset with `uv run python scripts/fetch_public_standards.py`; normal tests run offline against committed data.
